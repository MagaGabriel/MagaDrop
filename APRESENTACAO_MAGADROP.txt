MAGADROP
Roteiro da apresentação
Versão do aplicativo: 3.0.0
Atualizado em 6 de setembro de 2026

======================================================================
1. MAGADROP
======================================================================

Servidor de arquivos familiar para a rede local.

O MagaDrop transforma um computador Windows em um ponto central para guardar,
organizar e compartilhar arquivos. Celulares, tablets e outros computadores
acessam pelo navegador, sem instalar aplicativo cliente.


======================================================================
2. O QUE O MAGADROP FAZ
======================================================================

- Envia arquivos do celular para o computador.
- Mostra arquivos do computador no navegador.
- Permite baixar arquivos do computador para o celular.
- Cria pastas e organiza conteúdos pelo navegador.
- Mantém uma pasta pessoal para cada usuário.
- Oferece uma pasta compartilhada para a família.
- Administra contas, senhas e sessões.
- Continua funcionando na bandeja do Windows.


======================================================================
3. O QUE PRECISA SER INSTALADO
======================================================================

Para usar:

- Instalar apenas MagaDropSetup.exe em um computador Windows.
- Não instalar Java separadamente. O instalador já inclui o runtime necessário.
- Não instalar nada no celular. O acesso ocorre pelo navegador.

Para desenvolver:

- Git.
- JDK 25 ou compatível.
- PowerShell 7.
- Inno Setup 6 somente para gerar o instalador.


======================================================================
4. TUTORIAL DE INSTALAÇÃO
======================================================================

1. Abra MagaDropSetup.exe.
2. Conclua a instalação e abra o MagaDrop.
3. Se o Windows mostrar editor desconhecido, confirme apenas quando o arquivo
   tiver vindo do repositório ou de uma pessoa de confiança.
4. Permita o acesso do MagaDrop em redes privadas quando o Firewall perguntar.

O instalador cria o atalho MagaDrop e inclui o Java, a interface web, o ícone e
o desinstalador.


======================================================================
5. PRIMEIRA CONFIGURAÇÃO
======================================================================

1. Clique em Escolher... e selecione a pasta base.
2. Crie e confirme a senha do administrador MAGA.
3. Marque a inicialização com o Windows se desejar.
4. Conclua a configuração.

O programa não avança sem a escolha explícita da pasta base. Dentro dela, cria:

Pasta base
|-- Compartilhada
`-- Usuarios
    `-- uma pasta exclusiva para cada conta


======================================================================
6. ACESSO PELO CELULAR
======================================================================

1. Mantenha o MagaDrop aberto no computador.
2. Conecte o celular à mesma rede Wi-Fi.
3. Leia o QR code ou digite o endereço mostrado pelo MagaDrop.
4. Use o endereço do computador, não o endereço IP do celular.
5. Entre com MAGA ou com uma conta criada pelo administrador.

O computador precisa permanecer ligado e o servidor deve mostrar Pronto para
receber.


======================================================================
7. ARQUIVOS E USUÁRIOS
======================================================================

Cada usuário acessa sua área Pessoal e a área Compartilhada. Pelo navegador é
possível navegar, enviar, baixar, criar pastas e excluir itens. A exclusão move
o conteúdo para uma lixeira interna, evitando perda imediata.

O administrador MAGA pode criar membros, redefinir senhas, ativar ou desativar
contas, encerrar sessões e excluir membros. A conta principal não pode ser
desativada nem excluída.


======================================================================
8. SEGURANÇA E LIMITES
======================================================================

- Senhas protegidas com PBKDF2-HMAC-SHA-256 e salt aleatório.
- Sessões aleatórias com expiração, cookie HttpOnly e proteção CSRF.
- Limitação de tentativas de login.
- Bloqueio de caminhos, links e nomes de arquivo perigosos.
- Limite de 2 GB por arquivo.

O tráfego atual usa HTTP. O MagaDrop deve ficar em uma rede local confiável e
sua porta não deve ser exposta diretamente na internet. O acesso remoto seguro
será implementado depois de HTTPS e autorização de dispositivos.


======================================================================
9. SOLUÇÃO DE PROBLEMAS
======================================================================

Se o celular não abrir o endereço:

1. Confirme que celular e computador estão no mesmo Wi-Fi.
2. Digite o endereço completo mostrado pelo MagaDrop, incluindo http e a porta.
3. Desative temporariamente a VPN do celular para testar a rota local.
4. Confirme a permissão do Firewall em redes privadas.
5. Verifique se o roteador possui isolamento entre dispositivos.


======================================================================
10. COMPARTILHAMENTO E COLABORAÇÃO
======================================================================

Para outra pessoa instalar, envie apenas output\MagaDropSetup.exe. O instalador
não contém contas, senhas ou arquivos deste computador.

Para colaborar no código de um repositório privado, adicione a pessoa em
Settings > Collaborators > Add people no GitHub. Depois do convite, ela poderá
clonar a branch codex/v3-contas-sessoes e propor alterações.

Repositório: https://github.com/MagaGabriel/MagaDrop

Próximos marcos: restauração visual da lixeira, auditoria persistente, HTTPS,
autorização de dispositivos e acesso externo seguro.
